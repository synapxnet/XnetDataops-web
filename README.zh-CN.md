# XnetDataops Web 中文说明

XnetDataops Web 是由 **SynapXnet 团队**开源的企业级、多租户 DataOps 控制台，与后端仓库共同组成前后端分离系统。项目覆盖数据源、数据集成、数据开发、任务调度、质量、治理、资产、API、脱敏、可观测与审计。

完整的项目介绍、模块说明、在线体验、页面截图、部署方式与开源许可统一维护在 [README.md](./README.md)。

- 在线体验：<https://www.xnetdataops.synapxnet.cn>
- 后端仓库：[synapxnet/XnetDataops](https://github.com/synapxnet/XnetDataops)
- OpenXnet 开源社区：<https://openxnet.synapxnet.com>

前端基于 Vue 3、TypeScript、Ant Design Vue，并采用 [Vue Vben Admin](https://github.com/vbenjs/vue-vben-admin) 框架构建。项目遵循 MIT License，并依法保留上游框架的版权与许可声明。
